# Documentation Index

Use this tree to separate stable operating knowledge from in-flight delivery notes.

## Directories
- `evergreen/` - canonical product, architecture, API, and runbook material
- `product/` - active product shaping before it is promoted into `evergreen/`
- `delivery/` - reference-only delivery notes and supporting material

Promote stable decisions into `evergreen/`. Keep tactical delivery detail out of the canonical set.
